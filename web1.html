Definition

Web 1.0 refers to the first stage of the World Wide Web, where websites were static and users could only read information without interacting with it.

Explanation

Web 1.0 websites were mainly made up of static HTML pages. There was little to no user interaction, and content was controlled entirely by website owners. Users could view information but could not easily contribute or modify content.

Importance

Web 1.0 is important because it marked the beginning of the internet as a public information system. It laid the foundation for later developments such as Web 2.0 and Web 3.0, which introduced interactivity and user-generated content.
